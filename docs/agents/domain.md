# Domain documentation

This repository uses a single domain context.

Before engineering work, read:

- `CONTEXT.md` for domain language and invariants;
- `docs/adr/` for relevant architectural decisions, when present;
- `docs/tfdi-contract.md` for the verified TFDI runtime contract.

Use the terms from `CONTEXT.md` in tests, issues, reports, and implementation. Surface any conflict with an ADR explicitly instead of silently overriding it.
