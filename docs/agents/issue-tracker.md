# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues at `JCH2333/fenix_to_tfdi`. Use the `gh` CLI from this clone so it resolves the repository from `origin`.

## Conventions

- Create: `gh issue create --title "..." --body "..."`
- Read with comments: `gh issue view <number> --comments`
- List: `gh issue list --state open`
- Comment: `gh issue comment <number> --body "..."`
- Add or remove labels: `gh issue edit <number> --add-label "..."` or `--remove-label "..."`
- Close: `gh issue close <number> --comment "..."`

When a skill says to publish to the issue tracker, create a GitHub issue. When it says to fetch the relevant ticket, read that issue and its comments.
